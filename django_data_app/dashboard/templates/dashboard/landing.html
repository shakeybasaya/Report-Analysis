QuickSnap User Manual

Follow these steps to turn your spreadsheet into clean data, useful charts, and a downloadable report.

1. Create an account or log in

Sign up for a QuickSnap account or log in to access the data tools. Your account lets you work with your own active dataset.

{% if request.user.is_authenticated %}Start importing →{% else %}Create an account →{% endif %}

2. Import your dataset

Open Import and upload a supported CSV or Excel file. Check that your file contains the columns and records you want to analyze.

Go to Import →

3. Clean your data

Review the row and column counts, duplicate rows, and missing values. Remove duplicates or handle missing values before analyzing. If you continue without cleaning, results may be less reliable.

Go to Data Cleaning →

4. Explore charts and insights

Open Analysis, choose fields for your chart, and select a chart type. Use the recommended chart suggestions as a starting point, then adjust the fields and options to fit your question.

Go to Analysis →

5. Use the Pivot Table

Arrange fields into rows, columns, and values, then choose an aggregation such as Sum, Count, or Average to summarize your data. The pivot table is for temporary analysis and is not added to the PDF report.

Open Analysis →

6. Build your report

Add the charts you want to include to the report, review the selected items, and edit report text or findings when those options are available. Export the finished report as a PDF.

Go to Report Builder →

7. View report history

Open Report History to review reports that were saved previously, when that feature is available for your account.

Go to Report History →

Tips for better results

Use clear column names, check for missing or duplicated records, choose chart fields that answer one question, and confirm the chart labels and values before creating a report.

Remember: QuickSnap helps summarize and visualize your dataset. Always check the data and interpret the charts in context before using the results for decisions.
